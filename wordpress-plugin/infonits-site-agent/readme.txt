Read-only WordPress health reporting for Infonits Website Care.

== Installation ==

1. Upload and activate the plugin.
2. Open Settings > Infonits Site Agent.
3. Copy the Website Care URL, Site ID and Agent token from the Infonits Finance Website care page.
4. Save, then click Send health now.

== Data sent ==

WordPress version, PHP version, active theme name/version, available plugin/theme update counts, HTTPS state, debug state, plugin version and site URL. Posts, users, passwords and database content are never sent.
